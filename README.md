# 🧙‍♂️ Huntera Wiki

A modern, interactive game Wiki built to explore game data, featuring a Monster Bestiary, Hunting Grounds (Hunts with dynamic pulls), and a complete Item & Equipment Catalog.

Acesse aqui: [https://tronipm.github.io/huntera-wiki/](https://tronipm.github.io/huntera-wiki/)

---

## ✨ Features

- 👹 **Complete Bestiary:** Monster directory with filters for creature classes, elemental immunities (resistance = 0), and loot drops.
- 🗺️ **Hunting Grounds (Hunts):** Dynamic pull visualization displaying associated monsters and drop tables.
- 📦 **Item Catalog:** Over 700 categorized items featuring combat stats, elemental resistances/vulnerabilities, and reverse-lookup for monster drops.
- 🔍 **Unified Global Search:** Search for any keyword directly from the sidebar and get segmented results across Monsters, Hunts, and Items.
- 🌐 **Internationalization (i18n):** Multi-language support for English (en), Portuguese (pt-BR), and Spanish (es).
- 🌓 **Dark & Light Mode:** Seamless theme switching with local storage persistence.
- ⚡ **High Performance:** Fast, client-side data indexing and cross-referencing powered by Vue 3 and Pinia.
